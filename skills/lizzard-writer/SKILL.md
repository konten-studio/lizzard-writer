# Lizzard Writer

Brief in. Reel script out, ready to shoot.

"Lizard brain" is a shorthand, not a neuroscience claim. It stands for the fast gut check people make before they think: **"Am I in danger?"** or **"Is there an easy win here?"** A reel that hits one of those in the first second gets the scroll to stop. A reel that then pays off with something **smaller and simpler than expected** gets watched to the end, saved and shared. The target reaction:

> "Oh... hanya dengan begitu aja ternyata."

## The engine

```
HOOK (danger / happy, big stake)  →  OPEN LOOP  →  SMALL LEVERS, one by one  →  TWIST ("ternyata cuma gitu")  →  RELIEF + CTA
```

- **Danger mode:** a big fear, caused by something tiny and everyday. "5 kebiasaan kecil ini ternyata bisa bikin lutut lebih cepat aus."
- **Happy mode:** a big win, unlocked by something tiny and doable today. "Cukup gerakan 2 menit ini, lutut kerasa lebih enteng."

Big stake + small lever = twist. Big stake + big lever = homework. Small stake + small lever = trivia.

## Truth contract (non-negotiable)

The twist only works long-term if the payoff is real.

1. **The payoff is true and the reel shows it.** Never tease a "simple trick" the reel doesn't deliver.
2. **No invented fear.** Danger mode names a real risk. `bisa` ≠ `pasti`, `memperburuk` ≠ `menyebabkan`.
3. **No miracle cures.** In health, money and legal niches the small action is a *helpful step*, not a cure. Products are "membantu", never "menyembuhkan". Add "cek ke dokter/ahli" when stakes are real.
4. **Keep the source's claim ceiling.** No unsourced statistics. Don't upgrade anecdote to science.
5. **Paid ads:** avoid "kamu" + a personal condition ("Kamu kena diabetes?"). Use third person or general framing ("Banyak penderita diabetes...").
6. **Danger always ends in relief.** Never leave the viewer only scared.

If the brief asks for a claim that breaks this, refuse that one claim in a sentence and write the strongest true version.

## Workflow

1. **Read the brief.** Topic/product, audience (age, situation, fears, wants), platform, length (default 30-45s), language and register, CTA, and the facts you actually have. If a source is given (article, transcript, notes), pull the levers from it, don't invent them. Ask only if a missing fact changes everything.
2. **Map stakes.** 3-5 real fears (danger) and 3-5 real desires (happy), in the audience's words.
3. **Find small levers.** Everyday causes (danger) or tiny actions (happy). Smaller and more familiar = stronger twist. Must be true.
4. **Pitch angles.** 5 one-line angles, mixed danger/happy, at least 3 patterns. Each: hook + the "ternyata cuma ..." payoff. Score them (formula.md). Truth is a gate, not a score.
5. **Write the reel script** for the top angle (or top 3 if asked) using the output format below and the craft rules in reel-craft.md.
6. **Self-check** against the checklist at the end of reel-craft.md, fix, then deliver.

## Output format (default)

````
ANGLE: [DANGER|HAPPY · pattern] one line
AUDIENCE: who, one line
LENGTH: ~35s · 9:16

| Detik | Visual / B-roll | Teks di layar | Voice over |
|---|---|---|---|
| 0-3 | ... | HOOK TEXT (≤7 kata) | Hook line |
| 3-7 | ... | ... | Open loop |
| ... | ... | 1. ... | Lever 1 |
| ... | ... | ... | Twist line |
| ... | ... | ... | Relief + CTA |

CAPTION: 1-3 lines + CTA
COVER TEXT: ≤6 words
ALT HOOKS: 3 more first lines to A/B test (same body)
SAFETY: claims checked, wording notes (only if niche is regulated)
````

Also give the **voice-over as one clean block** (no table) so the creator can read it straight into a teleprompter.

Write in the audience's language. For Indonesian: spoken, not formal. Older audiences: polite and clear ("Bapak/Ibu" or neutral). Younger: casual. Never Malay or textbook Indonesian.
